Gas Monitor 烧录工作台

ESP32-S3 · TVOC-301 · SSD1306 · v0.1.0

一键烧录

当前浏览器不支持 Web Serial。请使用电脑端最新版 Google Chrome 或 Microsoft Edge。

选择新出现的 USB/JTAG、CH34x 或 CP210x 串口；不要选择蓝牙 COM25/COM26。

接线

TVOC-301
GND → GND
5V → 5V/VBUS
SDA/TX → GPIO5
AIO/SCL 不接
SSD1306 SPI OLED
GND → GND
VCC → 3V3
SCL → GPIO12
SDA → GPIO11
RES → GPIO10
DC → GPIO9

烧录后

  1. 手机连接 GasMonitor-XXXX，密码 gasmonitor。
  2. 打开 http://192.168.4.1。
  3. OLED 和网页同时显示 HCHO、TVOC、估算 eCO₂。

电脑没有识别串口

  1. 换到开发板另一个 USB-C 口。
  2. 更换已确认支持数据传输的 USB 线。
  3. 按住 BOOT，点按 RST，再松开 BOOT。
